# T18 CDVQA image-differencing baseline

- **H1:** On yes/no change-presence questions, differencing beats the train-majority answer. PASS only if the paired CI95 lower bound for the accuracy gain is >0 on each full test split.
- **H2:** On identical pairs, differencing says "no change" on at least 95% of change-presence questions on each full test split.
- **H3:** For each full test split, swapping dates changes <5% of the presence answers and flips >80% of the originally correct answers for each directional type. The flip statistic is a control, since an unchanged class can legitimately elicit "no" in both orders. Zero eligible answers are insufficient evidence.

## Scope and input counts

The CDVQA pair loader enumerates eight types. Counts below come from the official local QA files after validating the question-to-image and question-to-answer joins. Test1 is the CDVQA Test split. Test1 and test2 have different questions over the same pairs.

| Question type | Train | Val | Test1 | Test2 | Scope |
|---|---:|---:|---:|---:|---|
| change_or_not | 23048 | 5751 | 13882 | 5126 | Presence proxy |
| increase_or_not | 7715 | 1920 | 4600 | 1805 | Direction proxy |
| decrease_or_not | 7652 | 1922 | 4658 | 1754 | Direction proxy |
| change_to_what | 5012 | 1239 | 2991 | 2991 | Out: semantic destination |
| largest_change | 4800 | 1200 | 2904 | 2904 | Out: rank semantic classes |
| smallest_change | 4800 | 1200 | 2904 | 2904 | Out: rank semantic classes |
| change_ratio | 3200 | 800 | 1936 | 1936 | Out: semantic area ratio |
| change_ratio_types | 9740 | 2409 | 5811 | 11616 | Out: class-specific semantic area ratio |

Even binary questions are class-specific in CDVQA. Raw differencing sees the question type and pixels only, so it can give the same answer to several class-specific questions for one pair. It tests pixel cues for the yes/no labels, without establishing class identification.

## Fixed evaluation

- Use the official splits, checking pair-ID disjointness between train, val, and evaluation. Fit logistic regression separately per binary type on train, select regularization C from 0.01, 0.1, 1, 10 by val accuracy (smallest C wins ties), then score test1/test2 once. Seed 17. Train-majority breaks ties in favor of no.
- Question-only uses TF-IDF word unigrams and bigrams. Pixel-only uses RGB at native resolution. Record per-channel mean absolute difference, fraction with absolute difference >20 DN, and signed mean after−before, globally and on a 4×4 grid. Standardize numeric features using train. Apply the fitted classifiers unchanged to identical and swapped pairs.
- Oracle-mask uses the pixel features plus class fractions at both dates from supplied semantic masks. Build the color vocabulary on train and treat white as the dataset's nonsemantic background code. Oracle results require annotations at inference.
- Bootstrap whole image pairs with replacement, 2,000 reps, seed 17. Resample the same pairs for differences. Count all questions within sampled pairs. Require at least 10 gold yes and 10 gold no for each binary evaluation cell, and at least 10 originally correct answers and 10 originally correct yes answers for the directional flip statistic. Otherwise report insufficient support. Identical pairs have artificial no targets for presence, so use real-label support for the cell and report the no-answer rate.
- Report real accuracy and identical/swapped agreement with original labels for G3 comparability. These two agreements do not score against counterfactual ground truth. Also report identical no-answer rate and swap change or flip rate. G3 comparisons use the exact frozen question IDs, labels and pairs from commit 89fc5bf; do not compare full splits to the G3 sample or compare the three-type results to its eight-type macro.
