# T15 stage 1: flood baselines and a small model pipeline

Preregistered before any model run. Null results are reported as-is. If the
trained model does not beat Otsu, Otsu ships. Stage 1 runs baselines, synthetic
tests, an eight-train-chip overfit gate and timing only; no full training or
Kaggle execution/upload. Pack remains local under its licence restriction.

## Primary metric and reporting

Water IoU = TP / (TP + FP + FN), pooling counts over chips in a reporting group.
Target-valid pixels are exactly label != -1. Do not use accuracy or mean per-chip
IoU as the primary metric. Bootstrap whole chips with replacement, 2,000 resamples,
seed 17; report percentile 95% intervals of pooled water IoU. A zero-union group
has undefined water IoU (unknown/null), never a fabricated perfect score.

Report valid, test, bolivia, per-event groups within each split, and India-test
separately, with chip counts and coverage. Baseline predictions come from all-dry,
shipped Otsu, recomputed per-chip VH Otsu, and shipped JRC permanent water. Baseline
numbers are final measurements; test/bolivia numbers cannot tune any choices.
Report agreement and coverage of recomputed versus shipped Otsu, not an assumed
identity. Any uncovered mask/encoding ambiguity is resolved before baseline runs.

## Hypotheses and pass/fail rules

- H1: S1-only U-Net beats shipped Otsu VH on test water IoU. Pass only when the
  S1 model CI95 lower bound is strictly greater than the Otsu CI95 upper bound.
- H2: the same strict non-overlap rule on India-test.
- H3: S1+S2 beats S1-only on test water IoU. Pass only when the S1+S2 CI95 lower
  bound is strictly greater than the S1-only CI95 upper bound.

Overlapping intervals, ties, or an undefined required metric do not establish a
pass. No trained-model hypothesis is evaluated using the tiny overfit run. Report
all arms, including failures, with no selection based on test/bolivia.

## Training and controls

Seed 17; a small 1–8M-parameter U-Net. Inputs are S1 VV/VH or S1 plus all 13 S2
bands in the pack order. Normalize with stored train-only pack statistics; handle
input nodata explicitly. BCE + Dice on target-valid pixels only. Record optimizer,
learning rate, class weights, threshold, checkpoint SHA-256, normalization and YAML
configuration. Only flips and 90-degree rotations are allowed as augmentation.

Train on train; select checkpoint epoch using valid pooled water IoU only. Test
and bolivia are used only for final scoring, never choices. Blank inputs and
shuffled training labels are distinct controls with the same training pipeline.
Define near-B0 as at most B0 + 0.02 absolute water IoU on valid; if a control fails,
report that result and investigate rather than changing the threshold after seeing
it. Control success is a measurement, not a property guaranteed by wiring.

Tiny overfit: choose eight train chips with seed 17 before looking at held-out
scores; report the train-IoU curve and require >0.9. If not reached, stop and report.
Timing must not turn into full training: benchmark forward/backward without
optimizer updates on the full train split for each input mode, then extrapolate
and label estimates. No test/bolivia input enters the benchmark or overfit gate.
