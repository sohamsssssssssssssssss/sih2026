# T13: Indian region-held-out adaptation (preregistered before any run)

WorldCover fractions are labels from a map product, not ground truth. A null result
("it does not help") will be reported as-is. No result from a smoke run tests these
hypotheses. No Europe data enters adaptation or epoch/arm selection.

## Locked protocol

Seed 17. Fold A adapts on punjab, kerala, assam and tests on delhi, sundarbans,
rajasthan. Fold B swaps these sets. Within each adaptation region, a seeded 80/20
split provides train/validation patches. Test regions have no patch overlap with
adaptation; each Indian region is tested once. Validation alone selects epochs.

Arms: original checkpoint (none), adaptation-train-only statistics (renorm),
classifier-only training (head), all-weight training (full), and full training with
shuffled adaptation labels. Head/full/control use renorm statistics. Full uses
AdamW, BCEWithLogits loss family, cosine schedule, learning rate 1e-4 and at most
15 epochs. Control uses the same training recipe as full.

Metrics use trees, shrub_grass, cropland, built, water; a class enters a group's
macro average only with at least 10 positives in that group. The same eligible
class set and patches are used for every arm within each group. Report region,
fold-pooled and out-of-fold India-pooled mAP, bootstrap CI95, prevalence and
shuffled-score chance; preserve the original model baseline on identical data.
Report class eligibility explicitly; a missing eligible class is not imputed.

## Hypotheses and decision thresholds

H1: The best adaptation arm recovers at least half the original Europe-minus-India
mAP gap for each mode. Choose the best of renorm/head/full separately within each
fold using adaptation-validation mAP only (ties: renorm, head, full). Pool its
out-of-fold predictions for the final score. For each mode, let I0 be original
India mAP, E0 original Europe mAP, and Ia selected-arm out-of-fold India mAP on
the same five-class comparison set. Pass iff E0 > I0 and
Ia - I0 >= 0.5 * (E0 - I0). Overall H1 passes only if all three modes pass.
A nonpositive gap or unavailable comparison metric is reported as not evaluable,
not a pass. Compute E0 and I0 from the original checkpoint on this pack; do not
use rounded context numbers as thresholds. Include uncertainty without claiming
that a point-threshold pass proves statistical significance.

H2: Arm ranking is renorm < head < full. Pass per mode only if this strict ordering
holds for out-of-fold India-pooled mAP, using each arm's validation-selected
epochs. Ties fail. Overall H2 passes only if all modes pass. None is reported as
an anchor, not included in this ordering.

H3: Shuffled-label full controls stay at prevalence level. Operational tolerance:
absolute difference between out-of-fold control mAP and the prevalence baseline
must be <= 0.05 per mode; overall pass requires all modes. Report the difference
and CI even if this fails. A pretrained checkpoint can retain predictive signal
under shuffled fine-tuning, so this is a hypothesis, not a guaranteed sanity
check. Shuffled-score chance columns are distinct from shuffled-label training.

## Unresolved implementation choice

The checkpoint classifier has 19 BEN outputs; WC labels have six coarse outputs.
Existing transfer evaluation maps each coarse score to max sigmoid of its BEN
members. Before implementation, obtain approval either to retain the 19-output
head and apply BCEWithLogitsLoss to each coarse class's maximum member logit
(equivalent mapping), or to replace the head with six outputs. Do not infer fine
BEN labels from coarse WC labels. Record the resolved choice before any run.

## Limits

Patch-bootstrap intervals reuse the existing implementation and do not estimate
uncertainty over new regions. Only six India regions exist. Held-out regions are
used only for final scoring, never hyperparameters, epochs or arm selection.
Report all arms and controls regardless of direction. No claims about RISAT,
Cartosat, single-date imagery or accuracy against independently verified truth.

## Design decisions — 2026-11-16

Approved: retain the 19-output BEN classifier. A coarse logit is the maximum
of its mapped BEN member logits, sharing the mapping/pooling implementation with
transfer.py. Apply BCEWithLogitsLoss to coarse logits and the existing WC
fraction-to-presence labels. Mask coarse classes with no positives in adapt-train
from the loss. Unmapped BEN classifier outputs receive no loss or optimizer
update (including AdamW weight decay). Head adaptation freezes backbone weights
and BatchNorm buffers; full adaptation may update them. No fine BEN labels are
inferred from coarse labels.

Before adaptation, arm none must reproduce the existing per-region and pooled
India/Europe mAP using stored wc-*-logits.npy and ben-transfer.json within 1e-4;
a mismatch stops the run. The smoke subset is not a reproduction dataset: perform
the reproduction check on the complete pack first, then subset for smoke only.
