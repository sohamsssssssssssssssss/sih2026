# JSON Schemas — structural only

Structural schemas only. Cross-field rules (Answer status/confidence/refusal, Scene bounds order,
EvalRecord ci95, PackManifest splits sum) live in `core/schema.py`, which is authoritative.

- **Answer** — `refused` needs `refusal_reason` and forbids `confidence`; `answered` forbids `refusal_reason` and needs `primary`; `low_confidence` needs `primary`.
- **Scene** — `bounds` must be `(minx, miny, maxx, maxy)` with `minx < maxx` and `miny < maxy`.
- **EvalRecord** — `ci95` must bracket `value`: `lo <= value <= hi`.
- **PackManifest** — `sum(splits.values()) == n_patches`.
- **PackManifest** — `created` must be timezone-aware UTC (zero UTC offset).

Generated by `python -m core.schema` from the models in `core/schema.py`; do not edit by hand.

T08 adds optional `Answer.evidence`, `Evidence.needs_sensor`, and precise refusal
reasons in schema v1.2.0. Existing v1.1.0 values remain accepted. See
[router spec](../plan/ROUTER_SPEC.md) and [validation report](../plan/ROUTER_REPORT.md).
